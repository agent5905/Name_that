# Human acceptance failure record

## Corrective client gates

The rebuilt client now distinguishes the saved game library/editor from immutable live sessions. A host can create and edit definitions with 2–10 answers per question, select the correct answer, upload a normalized portrait, preview mystery/reveal states, host a fresh session, and use Play Again with an idempotent operation. The display, host, and participant views share the original Studio Mystery File system. The protected portrait is not requested before reveal; pre-reveal clients use only the server-provided silhouette derivative URL.

Permanent browser gates now cover library → host, editor draft/media/final update, varying answer counts, late-join eligible denominators, immediate reveal, Play Again retry identity, protected portrait release, presentation sizes, and mobile submitted/locked states. Screenshot review covers library, editor, lobby, question, locked, reveal, results, complete, host control, and participant phone layouts.

Recorded on 2026-08-11 against `https://name-that-team-member.pages.dev` at commit `e0f885d` before corrective implementation.

The prior release passed unit, mocked browser, live API, load-boundary, and deployment checks, yet it did not cover the product lifecycle a host actually needs. These six findings are the baseline for the replacement Gauntlet.

## Revised permanent gates

- Browser tests must exercise the real Pages Functions and Supabase backend for authoring, hosting, completing, replaying, editing, and late joining; mocked visual tests remain supplemental only.
- A saved game must produce multiple fresh session IDs/codes without carrying players, answers, results, phase, or Realtime topics forward.
- First-time join is tested independently in lobby, open, locked, reveal, results, and complete phases.
- Reveal fails if an alert, confirm, or modal is emitted.
- Content tests cover variable question and answer counts, reordering, replacement uploads, reload persistence, and immutable active-session snapshots.
- Fresh critics receive only the production URL and a human goal. Visual acceptance explicitly fails a generic dashboard/polling experience.
